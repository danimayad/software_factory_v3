## Claude Code

- Helper definitions for this project, when it has any, live in `.claude/agents/`.
  They are created from `factory-setup/helper-template.md`.
- Settings (permissions, sandbox, hooks), when the project has them, live in
  `.claude/settings.json`. They are the ones approved in the build plan. Do not widen
  them during the build.
- Tested examples of each configuration: `factory-setup/reference/claude-code/`.
